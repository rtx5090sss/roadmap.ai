# Frontend Design & Visual Excellence

When creating or modifying UI components:
- **Palette**: Use deep dark backgrounds (`#080c14`), subtle slate borders (`rgba(255, 255, 255, 0.08)`), and luminous accents (cyan `#38bdf8`, emerald `#10b981`, amber `#f59e0b`).
- **Glassmorphism**: Combine `rgba(15, 23, 42, 0.75)` with `backdrop-filter: blur(16px)` for depth.
- **Typography**: Inter for readability, Outfit for punchy headlines, JetBrains Mono for code.
- **Micro-animations**: Add transition curves `cubic-bezier(0.16, 1, 0.3, 1)`, hover lifts, and celebratory confetti on milestones.
- **Responsive**: Fluid containers, CSS Grid `repeat(auto-fit, minmax(280px, 1fr))`.
